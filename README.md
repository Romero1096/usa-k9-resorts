# USA K9 Resorts static site

This folder is the clean static deployment package. It contains the selected home page, FAQ, blog index, four article routes, supplied media, and the muted deck video. Earlier visual directions and evidence pages are not included.

## Route map

- `/` — home
- `/faq/` — FAQ
- `/blog/` — article index
- `/blog/leash-etiquette/`
- `/blog/board-and-train/`
- `/blog/socialization/`
- `/blog/boarding-tips/`

## Hosting handoff

Upload the *contents* of this folder to the primary domain document root. For a GoDaddy cPanel primary domain, that is normally `public_html`; extract a ZIP explicitly into that destination.

This package has not been uploaded, published, or connected to a domain. Current GoDaddy account hosting entitlement is unknown because its Products page required a sign-in.
